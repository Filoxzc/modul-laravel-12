# PBL – Mini SIAKAD Lite (TI032107)

Template ini **tanpa latihan**. Mahasiswa fokus menyelesaikan TODO pada folder `src/` agar UI di folder `public/` berfungsi.

## Setup DB (lokal)
Jalankan:
1. `sql/01_create_user_db.sql`
2. `sql/02_schema.sql`
3. `sql/03_seed.sql`

## Jalankan aplikasi (lokal)
```bash
php -S localhost:8000 -t public
```
Buka:
- Dashboard: http://localhost:8000/index.php
- Mahasiswa: http://localhost:8000/students.php
